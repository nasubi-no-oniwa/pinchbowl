# ピンチボウル

ボウリングのピンになって、球をよけろ！ 「投げる番」と「よける番」を3回ずつ交代する1対1。最後にピンがたくさん残っていた方が勝ち。

## あそびかた
- 100本のピンのうち1本が自分。はじめに自分になるピンをえらぶ
- よける番：スティックで動く（ジャンプなし）。動いてほかのピンにぶつかると、そのピンも倒れる
- ピンにたくさん当たって**青く光った球**はぶつかれば止められる。**赤い球**に当たるとふっとんで即負け
- 投げる番：左右ドラッグで位置、上スワイプで投げる（速さ＝スワイプの速さ、指を曲げるとカーブ）。ガードレールではね返る
- 倒れたピンは投げ終わるたびにかたづけられる（残ったピンは次の回もそのまま）
- CPU（かんたん／ふつう／むずかしい）、あいことば対戦（3人目からは観戦）

## ファイルの中身
| ファイル | 役割 |
|---|---|
| `index.html` / `css/style.css` | 画面 |
| `js/config.js` | **調整はここ**（レーンの長さ・球の速さ・曲がり・止められる速さ・投げる回数など） |
| `js/phys.js` | 物理（cannon-es）：ピン100本・球・自分のピン |
| `js/cpu.js` | CPU（投げる・よける） |
| `js/render.js` | 3D表示（three.js r158） |
| `js/input.js` | 操作（スマホ・PC・コントローラー） |
| `js/sound.js` | 音とBGM |
| `js/online.js` / `js/firebase-config.js` | あいことば対戦（ほかのゲームと同じFirebase） |
| `js/main.js` | 画面と試合の進行 |
| `lib/` | three.js / cannon-es |
| `assets/` | 効果音・BGM |
| `database.rules.json` | Firebaseに貼る安全ルール（全ゲーム共通。`pinchbowl` を追加） |
| `icon.html` | アイコンの元 |
